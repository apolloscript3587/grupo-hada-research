# Cronología resumida

| Año / periodo | Hito |
|---|---|
| 1956 | Fundación en Manizales como Jabonerías Hada por Mauricio Trujillo Correa y Gloria Posada de Trujillo. |
| 1956 | Incendio durante el primer año de operación. |
| 1962 | Constitución como corporación e incorporación de maquinaria europea moderna. |
| 1965 | Lanzamiento del jabón cosmético Cristalino. |
| 1970s | Expansión nacional y desarrollo de tecnología de jabón para marcas internacionales. |
| 1984 | Enfoque exclusivo en jabones cosméticos. |
| 2006 | Vinculación declarada al Pacto Global de Naciones Unidas. |
| 2010s | Aceleración de internacionalización y expansión de manufactura en Barranquilla y México. |
| 2023 | Certificación como Empresa B. |
| 2024 | Expansión productiva, crecimiento de ventas/exportaciones y consolidación mexicana en Tepotzotlán. |
| 2024/25 | Comunicación de certificación Carbono Neutro y acciones de descarbonización/reforestación. |
| 2025 | BID Invest publica propuesta de financiación para expansión/modernización de las operaciones colombiana y mexicana. |
