# Actualización de investigación — Grupo Hada — 2026-09-09

## Hallazgos recientes

### Actividad corporativa
La página pública de LinkedIn de Grupo Hada muestra publicaciones recientes en septiembre de 2026 y mantiene aproximadamente 41,3 mil seguidores. La empresa continúa comunicando manufactura por contrato en cuidado personal, limpieza, fragancias, hogar, higiene, productos industriales y velas.

**Confianza: Alta para actividad pública; media para inferir escala exacta.**

### HadaEcofire
Una publicación reciente describe el desarrollo de velas integrando cera, pabilo, fragancia, ingredientes, empaque y temperatura. Esto refuerza que HadaEcofire continúa activa como línea de desarrollo y manufactura.

**Confianza: Alta para continuidad de la línea; media para clientes concretos.**

### Perfumería
Otra publicación reciente comunica oportunidades alrededor del formato de perfume sólido. Es evidencia de innovación y exploración de formatos, pero no identifica por sí sola un lanzamiento o cliente específico.

**Confianza: Alta para la señal de innovación; baja-media para impacto comercial.**

### Vacantes
Se mantienen visibles publicaciones para **Analista de Nómina** y **Analista de Control de Calidad Nivel I** en Barranquilla. También permanece como antecedente la convocatoria de prácticas académicas en Barranquilla. El portal oficial de vacantes no refleja necesariamente el mismo detalle que LinkedIn, por lo que ambas fuentes se conservarán y se compararán.

**Interpretación:** estas publicaciones señalan actividad de soporte y aseguramiento de calidad, pero no demuestran por sí solas crecimiento neto de plantilla.

**Confianza: Alta para la existencia de las publicaciones; media para inferir expansión.**

### ESG y comunidad
Una publicación reciente comunica participación en iniciativas de conservación de ecosistemas y tortugas marinas con Educambio. Se registra como señal de relacionamiento ESG, no como cambio financiero u operativo.

**Confianza: Alta para la comunicación pública; media para impacto material.**
